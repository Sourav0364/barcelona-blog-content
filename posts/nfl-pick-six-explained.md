**What is a pick-six in the NFL?** It is a defensive interception returned all the way into the opponent’s end zone for a touchdown. “Pick” is football shorthand for an interception; “six” refers to the touchdown’s six points. An interception alone is not a pick-six—the return has to end in a touchdown.

## What happens during a pick-six?

The play starts with a forward pass intended for the offense. If a defensive player catches that pass, the NFL calls it an **interception** and possession changes. The play can continue with the interceptor running the ball. If the defender carries it across the opposing goal line into the end zone, the result is a touchdown—and that interception return is commonly called a pick-six.

The NFL’s [Football Operations glossary](https://operations.nfl.com/rules-officiating/nfl-football-basics/football-terms) defines an interception as a turnover in which a defensive player catches a forward pass, and defines a touchdown as a six-point score. The [2026 NFL Rulebook](https://operations.nfl.com/rules-officiating/2026-nfl-rulebook) provides the official rules for scoring and play outcomes.

## Pick-six vs. interception: the key difference

An interception changes possession, but it does not guarantee a touchdown. If the interceptor is stopped before reaching the end zone, the defense still takes possession, but the play is not a pick-six. The return must cross the opponent’s goal line for the touchdown.

| Play result | What happened | Pick-six? |
|---|---|---|
| Interception, return stopped before the end zone | A defender caught the forward pass; possession changed | No |
| Interception returned across the opponent’s goal line | The defender caught the pass and scored a touchdown on the return | Yes |
| Fumble recovered and returned for a touchdown | The defense scored after recovering a loose ball, not by intercepting a forward pass | No |

That distinction helps when following an NFL game: a turnover and a defensive touchdown are related, but they are not interchangeable terms. A fumble-return touchdown is a defensive score, while “pick-six” specifically describes an interception return touchdown.

## Why does “six” mean six points?

The NFL glossary lists a touchdown as worth **six points**. The “six” in “pick-six” refers to that touchdown, not to a guaranteed final score after any conversion try. The interception and the return are the play’s sequence; the touchdown is the scoring result.

## A quick way to recognize the play

When a defender catches a forward pass, first identify the turnover: the defense has possession. Then follow the ball carrier’s return. If the play ends before the opponent’s end zone, it remains an interception but not a pick-six. If the defender crosses the goal line with the ball, it is an interception-return touchdown.

## NFL pick-six FAQ

### Is every interception a pick-six?

No. An interception is a change of possession. It becomes a pick-six only if the defender returns the ball across the opponent’s goal line for a touchdown.

### How many points does a pick-six score?

The touchdown is worth six points. Any later conversion try is a separate part of the scoring sequence.

### Is a fumble-return touchdown a pick-six?

No. A fumble-return touchdown is a defensive score, but a pick-six specifically begins with an intercepted forward pass.

## The takeaway

A pick-six combines an interception with a touchdown on the return. If the defense catches the pass but does not score, it is still a turnover—just not a pick-six.
